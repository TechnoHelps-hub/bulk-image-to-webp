# Bulk Image to WebP Converter 🚀

A lightweight, production-ready Python script designed to batch-convert and optimize images (`PNG`, `JPG`, `JPEG`) into the modern, web-optimized `WebP` format. This tool helps web developers, designers, and site owners drastically reduce image file sizes to boost page loading speeds and improve SEO scores.

## ✨ Features
- **Batch Processing:** Convert an entire directory of images in a single click.
- **Smart Transparency Handling:** Automatically preserves alpha channels and handles PNG transparency flawlessly.
- **Custom Optimization:** Balance compression quality and file size perfectly (default set to 85% for crisp web results).
- **Clean Structure:** Pre-configured with `.gitignore` to prevent local cache tracking.
